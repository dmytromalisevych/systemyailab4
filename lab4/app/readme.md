# Локальний AI Асистент (Лабораторна 4)

## Як запустити:
1. Встановіть Ollama на ваш ПК.
2. Відкрийте термінал і запустіть сервер з дозволом CORS (це важливо для локальних веб-запитів):
   `OLLAMA_ORIGINS="*" ollama serve`
3. У новій вкладці термінала завантажте модель:
   `ollama pull qwen:0.5b`
4. Просто відкрийте файл `index.html` у будь-якому браузері (або запустіть через Live Server у VS Code).

## Обґрунтування параметрів генерації:
- **Модель:** `qwen:0.5b`. Обрана через малий розмір (близько 350 МБ), що дозволяє їй працювати миттєво навіть на комп'ютерах зі слабкими характеристиками, використовуючи CPU/RAM.
- **temperature: 0.3.** Оскільки застосунок розрахований на IT-допомогу, нам потрібні максимально детерміновані та точні відповіді без креативних "галюцинацій".
- **max_tokens: 150.** Жорсткий ліміт для захисту від зациклення. Малі моделі (до 1B параметрів) схильні до безкінечної генерації повторюваних символів при збоях контексту.
